
# Іван Франко — інтерактивний вебсайт

### 📖 Про проєкт
Навчальний вебпроєкт, присвячений життю, творчості та культурній спадщині Івана Яковича Франка. 

### 🎯 Мета проєкту
Популяризація української літератури та представлення постаті Івана Франка в сучасному інтерактивному форматі.

### 💻 Використані технології
- **HTML5** — структура вебсторінок.
- **CSS3** — дизайн, стилізація та адаптивна верстка.
- **JavaScript** — інтерактивні елементи та функціональність сайту.
- **Git та GitHub** — контроль версій і зберігання коду.
- **GitHub Pages** — публікація вебсайту.
